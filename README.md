# Pennywise

A personal expense tracker built with React, Tailwind CSS, Chart.js, and browser localStorage.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.

Expenses stay in the browser that created them. Use **Export CSV** to download the currently filtered entries. To publish, build the project and deploy the `dist` directory on Netlify or Render. This is a static client-side app and does not require a server.
